# MyTodo.Infrastructure - Notes

## Persistence Rules
- All database / entity framework related code should be placed in the `Persistence` folder.
- Entity Configurations (Fluent API) should be placed in the `Persistence/Configurations`, one configuration class file per entity. 
  - Naming convention: `<EntityName>Configuration.cs`
  - Each configuration class should implement `IEntityTypeConfiguration<T>` where `T` is the entity type.


## Folder Layout
- `Persistence/Configurations`: Contains entity configuration classes.
- `Persistence/DbContext`: Contains the DbContext class and related configurations.
- `Persistence/Migrations`: Contains migration files generated by Entity Framework.
- `Persistence/Repositories`: Contains repository implementation classes for data access.

## Conventions
- New entity classes should be placed in the `Domain/Entities` folder.
- New Entity: Always create a corresponding configuration class in `Persistence/Configurations`.
- Repository classes should implement interfaces defined in the `Application/Interfaces` folder.
- Define Base repository with common CRUD operations in `Persistence/Repositories/BaseRepository.cs` and inherit from it for specific entity repositories.

## Don'ts
- Avoid running project after making changes just build if you need to check for compilation errors.
